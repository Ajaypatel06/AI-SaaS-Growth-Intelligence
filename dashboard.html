Key Insights
REWRITE EFFECT
Rewrite adopters churn 28.3% vs 40.8% (χ² = 308.7, p < 0.001). In this simulation that link is built in; Part 2 tests the onboarding change.
CHURN PEAK
Days 21-27 after first AI output holds 35.7% of all churn. A check-in around day 14 reaches users just before it.
CHURN MODEL
Logistic regression, 18,033 eligible users: ROC-AUC 0.63. Explanatory only — a weak predictor.
